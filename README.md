# Platanízzate

Aplicación académica desarrollada con Streamlit para personalizar pedidos de pizzas con base de plátano verde.

## Archivos

- `app.py`: aplicación principal.
- `requirements.txt`: dependencias requeridas.

## Ejecutar localmente

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Publicar

1. Subir los archivos a un repositorio público de GitHub.
2. Ingresar a Streamlit Community Cloud.
3. Crear una nueva aplicación.
4. Seleccionar el repositorio y la rama `main`.
5. Indicar `app.py` como archivo principal.
6. Presionar Deploy.
